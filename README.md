# 메세지퍼 안드로이드 시제품 (미검증 소스)

카카오톡·인스타그램 DM 입력창을 접근성 서비스로 읽고, 부적절하면 전송 버튼 위에 지퍼 덮개를 띄웁니다.

## 설치 순서
1. 컴퓨터에 Android Studio 설치 (https://developer.android.com/studio)
2. 이 폴더(MessaZipper)를 `File > Open`으로 열기 → Gradle Sync가 끝날 때까지 대기 (처음엔 몇 분)
3. 폰: 설정 > 휴대전화 정보 > 소프트웨어 정보 > 빌드번호 7번 터치 → 개발자 옵션 > USB 디버깅 켜기
4. USB 연결 후 상단 ▶ Run
5. 폰에서 메세지퍼 실행 → "접근성 설정 열기" → 설치된 앱 > 메세지퍼 켜기
   (삼성 폰은 "다운로드한 앱" 안에 있고, "제한된 설정" 경고가 뜨면 앱 정보 > 점3개 > 제한된 설정 허용)
6. 카톡을 열면 오른쪽 위에 모드 버튼이 뜹니다. 윗사람 모드로 바꾸고 "오늘 교회 째껴야지~ ㅋ" 입력.

## 구조
- `ZipperService` 입력창 감지·판정·덮개 제어
- `Overlay` 화면 위 UI (TYPE_ACCESSIBILITY_OVERLAY라 '다른 앱 위에 표시' 권한 불필요)
- `Judge` 규칙 판정 + 로컬 변환, `Llm` OpenAI 변환(키는 앱에서 입력)
- `MainActivity` 설정 화면

## 알려진 한계 (솔직하게)
- 이 소스는 컴파일·실행을 해보지 못했습니다. 빌드 오류가 나면 오류 문구를 그대로 알려주세요.
- 전송 버튼은 화면의 "전송/보내기" 라벨로 찾습니다. 못 찾으면 입력칸 오른쪽 끝에 대략 덮습니다.
- 덮개는 전송 버튼을 시각·터치로 가리는 방식이지, 앱의 전송 자체를 막는 것은 아닙니다 (엔터키 전송 등은 못 막음).
- 방(대화상대) 자동 인식은 안 하고 모드 버튼으로 수동 전환합니다.
- 인스타그램은 버전에 따라 입력창 감지가 안 될 수 있습니다.
